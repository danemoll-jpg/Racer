# Racer project instructions

Before making any project changes, read and follow [CODEX_RULES.md](CODEX_RULES.md), then read [PROJECT_TODO.md](PROJECT_TODO.md).

CODEX_RULES.md contains mandatory standing workflow/release rules for every task, even when the prompt does not repeat them. Wherever it says "Codex", it means the coding agent (Claude Code). PROJECT_TODO.md is the authoritative source for project state, bugs, decisions, backlog and current work. Older history lives in PROJECT_TODO_ARCHIVE.md: search it when a rule or bug needs history; do not read it end to end.

A later explicit instruction from Dan may override a standing rule for that task. Do not modify or weaken CODEX_RULES.md without an explicit standing-rule change request from Dan.
