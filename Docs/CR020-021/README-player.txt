RACER 0.2.0-review1 - WINDOWS SOLO PLAYTEST

Extract the COMPLETE ZIP into an ordinary folder before playing. Open the
extracted folder and double-click Racer.exe. Keep Racer_Data, MonoBleedingEdge,
UnityPlayer.dll and the other runtime files beside the executable. Unity Editor
is not required. This is a Windows x64 package; other operating systems need
separate builds. Internet access, an account and multiplayer are not required.

CONTROLS
Drive: W / Up or controller RT
Brake / reverse: S / Down or LT (hold through a stop to reverse)
Steer: A/D, Left/Right or left stick
Reset car: R or Y (abandons current lap; race clock continues)
Pause/resume: Enter / Esc or Start
Menus: arrows / D-pad / stick; Space / A confirms; Esc / B goes back
Start race, wait for GO, then cross START. Complete three laps through the
ordered gates. Restart Race resets the race and restores breakable props.

SETTINGS AND SAVES
Settings includes Master, Ambience, Race/UI and Vehicle volume, VSync and a
frame limit. Volume buttons cycle in 10% steps. Changes save automatically.
Records/settings live in your Windows user profile under
AppData/LocalLow/DefaultCompany/Racer/Phase7/street-loop-gates-v1-laps3.
No personal or test saves are supplied in this archive.

REVIEW LIMITATIONS
Vehicle sound is original procedural arcade synthesis, not a real engine
recording. Realism, repetition and speaker/headphone balance await listening
review. Physical-controller coverage and a friend's computer are unverified.
Extreme angled jumps/impacts can upset the car; use reset. Approximate homes,
placeholder wheel animation and the existing visual limitations remain.
No online play. See VERSION.txt for the exact committed source and LICENSES
for audio/asset and third-party notices. Please retain those notices.

Please test a complete race, acceleration/coast/brake/reverse, a normal corner
and skid, off-road/jump/landing/prop sounds, each volume/mute, pause/restart,
and settings/bests after quitting and reopening. Report your PC/controller,
resolution, sound device, and any missing or harsh sounds or stalls.
