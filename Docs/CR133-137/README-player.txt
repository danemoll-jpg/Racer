Woodstock Rush 0.24.0-review1

Corrective release: straight Laurel jump approach, continuous mountain
junctions and supported mountain roads in both directions, and recovery that
advances after stable post-jump driving.

Controls, vehicle handling, intentional jumps and Highway 92 remain unchanged.
R / controller Y performs local recovery. Detailed driving and jump acceptance
is reserved for Dan; no full-race playthrough or handling-tuning pass was run.

Play-Racer.cmd retains its normal Builds/Latest/Racer.exe entry point.
The signed GitHub update catalog uses the existing component updater format.
