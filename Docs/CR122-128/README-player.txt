Woodstock Rush 0.22.0-review1 / road, jump, and recovery corrections

Forward and Reverse Mountain Loop: connected road collision surfaces retain the
mountain elevation profile. Forward jump warning signs are planted beside the
approach. Landing support uses the same mesh as the visible road.

Reverse Downhill Ridge Cut: build speed, line up, and jump over the regular road
onto the far-side shortcut. A timber separator prevents the misleading left turn.
Laurel Switchbacks: restored local approach, takeoff and landing above the valley
driveway. The house and valley remain.

Recovery now needs one second of stable supported travel and excludes jump
run-ups/ramps. Successful stable landings become recovery references; resets use
established positions rather than searching backwards onto a ramp.

Vehicle performance is unchanged. Detailed gameplay acceptance is for Dan's
in-game review; no repeated automated driving/tuning pass was performed.

Use Play-Racer.cmd in the project for the latest packaged local release.
Existing signed-launcher installations obtain game updates from the GitHub
latest catalog. This release preserves the current soundtrack component.
